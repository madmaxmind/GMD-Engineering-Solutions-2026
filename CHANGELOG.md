# Historial de cambios

## V2.0.0 — primera entrega modular para revisión

- Nueva arquitectura de página corporativa.
- Se preservan las cuatro líneas raíz confirmadas en la consolidación estratégica de GMD.
- Machine Passport se presenta como solución de implementación y estructuración de expediente, con demo MVP identificada como demostrativa.
- Se separan estilos, configuración de contacto y comportamiento JavaScript.
- Se incorporan variantes de logotipo y un favicon SVG.
- Se documentan pendientes que requieren confirmación del responsable de GMD.
- No se publican métricas económicas ni porcentajes sin evidencia.

- Paquete revisado: se incluyen vistas previas HTML autocontenidas para abrir localmente sin dependencias de CSS/JS/imagenes externos.


## Ajuste visual — fondos de capacidades y perfil
- Se incorporaron fotografías del collage de servicios como fondos de baja intensidad en las cuatro tarjetas de capacidades GMD, con capas oscuras para preservar legibilidad del texto.
- Se sustituyó la imagen única del perfil por un mosaico de fotografías de diseño, recorrido en planta, colaboración e inspección técnica.
- Las imágenes se optimizaron a WebP y se integraron localmente en `assets/img/`.


Actualización visual: se sustituyó la imagen conceptual principal de Machine Passport por una fotografía de la placa física compartida por GMD y se añadió una galería con vistas frontal y posterior. El pie de imagen aclara que es una muestra física, no una instalación documentada en planta.
